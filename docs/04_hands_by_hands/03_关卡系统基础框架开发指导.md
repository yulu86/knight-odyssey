## 📋 Story分析

### 作为一名玩家
**我想要** 在不同的关卡之间切换
**以便** 体验多样化的游戏内容和挑战

### 验收标准（AC）
- ✅ 当我 `完成1-1关卡` 时，系统应`解锁1-2关卡`
- ✅ 当我 `进入关卡` 时，系统应`显示关卡名称和主题背景`
- ✅ 当我 `到达终点旗帜` 时，系统应`显示结算界面并计算总分`
- ✅ 当我 `选择已解锁关卡` 时，系统应`允许重玩之前的关卡`
- ✅ 当我 `关卡进度` 时，系统应`自动保存到配置文件`
- ✅ `关卡加载时间小于2秒`
- ✅ `每个关卡有独特的主题和视觉风格`

### 技术实现要点
- LevelManager作为AutoLoad单例管理关卡数据
- TileMap构建关卡地形
- 与GameManager、SaveManager、EventBus集成
- 使用ConfigFile保存关卡进度

---

## 🏗️ 实现方案设计

### 架构设计

```
LevelManager (AutoLoad Singleton)
├── 关卡数据管理
│   ├── LevelData类：关卡元数据（名称、主题、路径、解锁状态）
│   ├── 关卡列表：Array[LevelData]
│   └── 当前关卡：LevelData
├── 关卡状态管理
│   ├── 关卡进度：已完成的关卡列表
│   ├── 最高分数：每个关卡的记录
│   └── 收集状态：金币、水果收集进度
├── 关卡加载
│   ├── load_level(level_id)：加载指定关卡
│   ├── 当前关卡场景：PackedScene缓存
│   └── 异步加载支持
└── 关卡完成检测
    ├── level_completed(level_id)：标记关卡完成
    ├── unlock_next_level()：解锁下一关
    └── save_level_progress()：保存进度
```

### 数据结构设计

```gdscript
# LevelData结构
class LevelData:
    var level_id: String           # 关卡ID (如 "1-1")
    var level_name: String         # 关卡名称
    var scene_path: String         # 场景文件路径
    var theme_type: String         # 主题类型 (grassland/forest/cave)
    var is_unlocked: bool          # 是否已解锁
    var is_completed: bool         # 是否已完成
    var high_score: int            # 最高分数
    var coins_collected: int       # 收集的金币数
    var total_coins: int           # 关卡总金币数
```

### EventBus信号扩展

需要在EventBus中添加以下信号：
- `level_loaded(level_id: String)` - 关卡加载完成
- `level_started(level_id: String)` - 关卡开始
- `level_completed(level_id: String, score: int)` - 关卡完成
- `level_unlocked(level_id: String)` - 关卡解锁
- `checkpoint_reached(checkpoint_id: String)` - 到达检查点
- `level_progress_saved(success: bool)` - 关卡进度保存

## 📝 注意事项

### 开发建议
1. **优先完成核心功能**: 先实现LevelManager的基本功能，再完善UI
2. **小步迭代**: 每个Task都要运行测试，确保持续集成
3. **保持简单**: 避免过度设计，只实现必要功能
4. **及时重构**: 测试通过后，思考代码是否可以优化

### 常见陷阱
1. **忘记连接信号**: 确保所有信号都正确连接
2. **AutoLoad命名**: 不要使用class_name在AutoLoad脚本中
3. **场景切换**: 使用GameManager.load_scene而不是直接切换
4. **数据持久化**: 确保每次进度变化都保存
5. **测试数据清理**: 每个测试前后都要清理测试文件

### 调试技巧
1. **使用Godot Debugger**: 查看节点树和变量状态
2. **添加打印语句**: 在关键逻辑处添加print()
3. **检查事件总线**: 监控EventBus信号是否正确发送
4. **验证存档文件**: 检查user://目录下的存档内容
